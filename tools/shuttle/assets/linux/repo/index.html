Shuttle Browser packages

Signed package repositories for Shuttle on Linux (x86_64). Updates then come through your package manager.

Debian / Ubuntu (apt)

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL @URL@/shuttle.gpg | sudo tee /etc/apt/keyrings/shuttle.gpg >/dev/null
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/shuttle.gpg] @URL@/apt stable main" | sudo tee /etc/apt/sources.list.d/shuttle.list
sudo apt update && sudo apt install shuttle

Fedora (dnf)

sudo curl -fsSLo /etc/yum.repos.d/shuttle.repo @URL@/rpm/shuttle.repo
sudo dnf install shuttle

Signing key

shuttle.asc (armored) or shuttle.gpg (binary).
