# Prune manifest: platforms and apps Agent Chrome (macOS desktop) never builds.
# Applied by scripts/prune.py. A file is deleted only if it matches a rule here
# AND no build config we use reads it (siso inputs + deps log + gn files).
# Rule types:
#   dir <path>        everything under <path>
#   segment <name>    any directory named <name>, anywhere
#   suffix <name>     files named *_<name>.<ext> or *_<name>_*.<ext>
#   ext <ext>         files with this extension
#   keep <path>       never prune under <path> (wins over all rules)
